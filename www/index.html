📱 APK Studio v5 · tavsif → ilova → APK

Qanday ilova kerak?

Nom va tavsifni yozing, qolganini AI qiladi: avval o'xshash ilova/o'yinlarni izlab o'rganadi, eng yaxshi yo'nalishni tanlaydi, keyin kodni yozadi, sinaydi, xatosini tuzatadi va GitHub'da APK yig'adi.
«O'zgartirish» — hozirgi ilovaga yozganingizni qo'shadi (masalan: «o'yinni tezroq qil»).

📂 Tayyor HTML'dan APK

O'zingizdagi HTML faylni tanlang. U o'zgartirilmaydi (faqat fayl yuklash yordamchisi qo'shiladi), to'g'ridan-to'g'ri APK'ga o'raladi. Fayl bilan birga rasm, CSS, JS, ovoz kabi qo'shimcha fayllarni ham birga tanlashingiz mumkin.
Yuklangach «Ko'rish» da tekshirib, «APK» bo'limida yasaysiz. AI bilan o'zgartirmoqchi bo'lsangiz, yuqoridagi tavsifga yozib «O'zgartirish» bosing.

APK yasash

Ilova GitHub'ga yuklanadi, GitHub uni 3–6 daqiqada APK'ga aylantiradi va havola beradi.
Jurnal bo'sh

1-qadam. GitHub akkaunt (bir marta)

  1. github.com ga kirib bepul akkaunt oching.
  2. Quyidagi tugma orqali token yarating: Expiration — 90 days, pastga tushib Generate token bosing. repo va workflow allaqachon belgilangan bo'ladi.
  3. Chiqqan ghp_... kodni nusxalang (u faqat bir marta ko'rinadi) va ⚙ Sozlamalarga qo'ying.
🔑 Token yaratish sahifasi

2-qadam. AI kaliti (bir marta)

  1. Bepul Gemini kaliti: aistudio.google.com/apikey → Create API key.
  2. Kalitni ⚙ Sozlamalarga qo'ying.
🤖 Gemini kalit sahifasi

3-qadam. Ishlatish

  1. Yaratish bo'limida ilovani tasvirlang → «Yangi yaratish».
  2. Ko'rish da sinab ko'ring, kerak bo'lsa «O'zgartirish» bilan tuzating.
  3. APK bo'limida «APK yasash» bosing.
  4. Tayyor bo'lgach yashil tugma chiqadi → bosing → .apk yuklanadi.
  5. Faylni oching. Telefon «noma'lum manba» ruxsatini so'rasa, ruxsat bering va o'rnating.

Orqada nima bo'lyapti? (o'rganish uchun)

  1. Repository — GitHub'dagi loyiha papkasi. Tool uni o'zi ochadi.
  2. Capacitor — HTML ilovani Android ilovasiga o'raydigan vosita (ichida WebView).
  3. GitHub Actions — GitHub'ning bepul serveri. .github/workflows/build.yml faylidagi buyruqlar bo'yicha APK'ni yig'adi.
  4. Release — tayyor APK shu yerga joylanadi, shu yerdan yuklab olinadi.
Bu debug APK: telefonda o'rnatiladi, lekin Play Market uchun alohida imzo kerak bo'ladi.

📲 Ilova ruxsatlari (avtomatik)

Fayl yuklash/saqlash, ulashish va telefon xotirasiga kirish har bir APK'ga avtomatik qo'shiladi. Qo'shimcha ruxsatlar:

AI

🔑 Gemini kalit olish (bepul) 🔑 OpenRouter kalit olish 🔑 Anthropic (Claude) kalit olish
Ikkalasini ham kiritib qo'ying. Ishlatiladigani yuqoridagi «Provayder»dan tanlanadi.
Model nomi eskirsa, provayderning saytidan yangisini ko'rib shu yerga yozing. Bepul: Gemini kaliti yoki OpenRouter'dagi :free bilan tugaydigan modellar.
Sifatni oshiradi, lekin har ilova uchun 3–5 ta so'rov sarflaydi (bepul limitga e'tibor bering).
Har qatorga provayder:model. Dastur yuqoridan boshlaydi, xato bo'lsa (pul tugasa, limit to'lsa, model o'chsa) keyingisiga o'tadi. Faqat kaliti kiritilgan provayderlar ishlatiladi. Tushunmasangiz, tegmang: dastur o'zi to'ldiradi.

GitHub

🔑 GitHub token olish
Ochiq repoda Actions cheksiz bepul. Yopiqda oyiga 2000 daqiqa.

🧠 Agentlar (90+ model)

Kalitlaringizdagi barcha jonli modellar yig'iladi va kodlash kuchi bo'yicha saralanadi. Reja, ikonka, kod, tuzatish — har biriga o'z agenti: arzon/bepul modellar oldinda, kuchlilari faqat kerak bo'lganda.
Kalitlar faqat shu brauzerda saqlanadi va faqat Google/OpenRouter/GitHub'ga yuboriladi. Begona qurilmada ishlatmang.
